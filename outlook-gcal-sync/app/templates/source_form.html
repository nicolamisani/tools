Exporting from a Mac

In Calendar.app, select the calendar in the sidebar, then File → Export → Export…. That writes one .ics containing the whole calendar, which is what this source expects.

Outlook for Mac's own File → Export produces a .olm archive, which is not iCalendar and will be rejected.

Uploading from a script instead

Push the same file over HTTP to automate this:

curl -T calendar.ics \ -H "Authorization: Bearer {{ source['push_token'] }}" \ {{ push_url }}

Each upload triggers a sync. Treat this token like a password — it allows writing to the Google calendar this source owns.

Where do I find the Outlook ICS link?
  1. In Outlook on the web, open Settings → Calendar → Shared calendars.
  2. Under Publish a calendar, pick the calendar and choose Can view all details.
  3. Click Publish and copy the ICS link — not the HTML one.

If publishing is greyed out, your administrator has disabled it — use the uploaded-file option instead.
