Where do I find the Outlook ICS link?
  1. In Outlook on the web, open Settings → Calendar → Shared calendars.
  2. Under Publish a calendar, pick the calendar and choose Can view all details (or Can view when I'm busy if you only want busy blocks).
  3. Click Publish and copy the ICS link — not the HTML one.

That link is a secret: anyone holding it can read the calendar. If your workplace has disabled publishing, the option will be greyed out — the alternative is an admin-registered Microsoft Graph app, which this version does not support.
